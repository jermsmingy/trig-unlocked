What this covers (Common Core grade 3, Number & Operations: Fractions):

  • 3.NF.1 A fraction 1/b is one of b equal parts of a whole; a/b is a of those parts. Missions 1, 2, 3.
  • 3.NF.2 Fractions on a number line: partition 0 to 1 into b equal parts, mark a/b by counting a lengths of 1/b, including fractions greater than 1. Mission 4.
  • 3.NF.3a–b Equivalent fractions are the same size or the same point on a number line (1/2 = 2/4 = 4/8, 1/3 = 2/6, 2/3 = 4/6, 3/4 = 6/8). Mission 5.
  • 3.NF.3c Whole numbers as fractions (3 = 3/1, 4/4 = 1, 8/4 = 2). Mission 7.
  • 3.NF.3d Compare two fractions with the same numerator or the same denominator, record with <, >, =, and justify with a model. Mission 6.
  • Mission 8 mixes all of the above. Denominators used: 2, 3, 4, 6, 8 (the grade-3 set).

Tips: Ask "How many equal pieces is the whole cut into?" before "How many are shaded?" Use real objects too: fold paper strips, cut sandwiches, share crackers. When comparing fractions with the same top number, ask "Which pieces are bigger?" (fewer pieces in the whole means bigger pieces). Comparisons only make sense when both fractions refer to the same size whole.
